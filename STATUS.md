# Lancius Current Status

Current internal milestone: **v11A3**
Previous internal milestone: **v11A2**
Public equivalent: **V1.1-AlphaRC3**
Release line: **1.1 development cycle**

## Phase

v11A3 is a freeze and hardening milestone.

The purpose of v11A3 is not to add new features.

The purpose is:

- hardening
- validation
- regression defense
- documentation cleanup
- release-candidate preparation

## Feature freeze

Starting with v11A3:

- no new operators
- no new runtime subsystems
- no new training features
- no new model-format changes unless required for correctness/security

Only bug fixes, validation, and release preparation are allowed.

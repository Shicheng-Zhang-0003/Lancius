# Lancius v11A2 Scope

> v11A2 is a development milestone.
> It is not a stable release.

## Theme

Transformer runtime usability.

## Included in v11A2

- Proper KV-cache runtime object
- Cleaner autoregressive generation path
- Transformer known-answer tests
- Expanded ONNX converter usability
- FP32 matmul kernel path
- More honest transformer execution demos

## Not included in v11A2

- GPU acceleration
- Dynamic shapes
- Full production training support
- Final binary compatibility guarantees
- A3-level hardening freeze

## Deferred to v11A3

- Format freeze preparation
- Compatibility contract review
- Full sanitizer gauntlet
- Adversarial model-loading hardening
- Release-candidate stabilization
